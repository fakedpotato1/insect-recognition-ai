# Incest Recognition AI

## Overview
This project aims to develop an **insect classification system** 
based on image analysis. The system focuses on implementing 
artificial intelligence algorithms, 
including feature extraction, neural networks and so on,
rather than relying on pre-trained deep learning models.


## Project Structure

```text
project/
│
├─ ai/          # AI algorithms and model training
├─ backend/     # Backend services and API endpoints
├─ frontend/    # User interface and application pages
├─ docs/        # Project documentation and reports
└─ README.md    # Project overview and setup guide
```

## Planned Workflow
```text
Image Input
     ↓
Image Preprocessing
     ↓
Feature Extraction
     ↓
Feature Selection / Optimization
     ↓
Neural Network Classification
     ↓
Prediction Result
```

## Dataset
Dataset: IP102

The dataset contains insect images belonging to 
multiple pest categories and will be used for training 
and evaluation.
